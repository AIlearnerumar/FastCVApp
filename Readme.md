# FastCVApp - OpenCV Image Processing Web Tool

FastCVApp is a lightweight web interface built using FastAPI and OpenCV that allows users to upload an image and apply various image processing operations, including filtering and edge detection.

## 🔧 Features

- Upload image via web interface
- Apply common OpenCV operations:
  - Gaussian Filter
  - Median Filter
  - Bilateral Filter
  - Canny Edge Detection
  - Sobel Edge Detection
- View processed image in browser
- Download the result directly
